Quadra 0.40 starts Roblox straight away and keeps the settings out of the way until you ask for them.

- **Direct start:** `quadrahq` now shows a small splash (logo, progress, Cancel), updates Roblox if a newer version is out, and starts the game. The settings window opens from the tray icon, from `quadrahq --settings` (also in a running Quadra), or from the shortcut's right-click **Settings** action (reinstall to get the action on an existing shortcut). It still opens by itself for first-time setup, a missing client and errors. **Open settings after Roblox exits** replaces **Show the launcher after Roblox exits**, and Quadra now closes with the game unless you turn it on.
- **New layout:** a sidebar with Home, Servers, Mods and Studio; a ROBLOX group (Roblox, Game, Fast flags, Quadra M2VK, Rosemary, VR, CiderDarling); and Configuration (Appearance, Integrations, Network, Environment, Diagnostics). Home shows the Roblox/Studio choice, status cards and your recent games.
- **Servers:** history of the servers you joined, with Rejoin; optional **Join by region** through RoValra's server list (RoValra sees the game id and the region, not your account); join by id or roblox.com link. A desktop notification tells you where the server is when **Show server location** is on.
- **Rosemary (experimental):** Settings → Rosemary installs Rosemary and the macOS client and can run Roblox through it instead of Darling. No mods, Discord status or web sign-in window yet; start games from roblox.com.
- **Smaller:** Fast flags Roblox ignores get a warning icon (Roblox's own allowlist); a mod crash guard sets aside new mods after a quick crash; **Block Roblox telemetry** through the DNS forwarder; a note when the game you joined was updated in the last day; an experimental CPU core limit; a VR icon.
- Everything in the 0.37 to 0.37.p4 notes still applies.

Validation: Rosemary was tried in a live Roblox game on one machine (it joined a server; with MangoHud it crashed until MangoHud was switched to its Vulkan layer variable). The direct start, tray protocol, history, region lookup, crash guard and the new pages were tested headless, with 41 unit tests that pass; the tray was checked against a fake panel, not a real one. Not tried in a game: Rejoin and region joining (they hand Roblox a `roblox://` link), the CPU limit, the telemetry block and the crash guard on a real crash.

Fully close and reopen Quadra after updating. Studio is not in the Flatpak. OpenGL remains the default for the game; VR requires OpenGL or Vulkan/Zink. Native packages include the matching Metal host and framework. Install `.pkg.tar.zst` on Arch derivatives, `.deb` on Ubuntu 24.04+/Debian 13+, or the binary `.rpm` on current Fedora. Darling/CiderDarling downloads remain separate. Source archives, build recipes and `SHA256SUMS` are attached.
