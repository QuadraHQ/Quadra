Quadra 0.43.0 keeps the launcher's pages in step through one shared state, makes Discord Rich Presence work with Flatpak and Snap Discord clients, and moves the Flatpak to the GNOME 51 runtime, which is now attached to releases.

- **Settings stay in step:** the pages share one state, so a change in Settings shows on the Play page, in the tray and on the Studio page straight away. The Play page shows the renderer in use, following Rosemary's Force OpenGL switch.
- **Discord Rich Presence:** found when Discord runs as a Flatpak or a Snap (Discord, Discord Canary, Vesktop), not only when it is installed natively. Game names and icons are looked up again while you play, placeholder names are never shown, and the game icon appears when Show game icon is on. Problems are printed in the launcher's output with Discord's reason.
- **Up-to-date GTK:** the file pickers use GTK's file dialog and the dark style follows the system through GTK's colour scheme. The launcher needs GTK 4.12 or newer.
- **Flatpak:** built on the GNOME 51 runtime instead of bundling GTK, libadwaita and WebKitGTK, and it can reach the Discord, Discord Canary and Vesktop Flatpaks for Rich Presence. The release now includes `quadrahq-0.43.0-x86_64.flatpak`.
- **Nix:** a Rosemary variant of the package and module; the CiderDarling Metal host hash is fixed.
- **Releases** start on their own when a `Release` commit that bumps the version reaches `main`.

Validation: the launcher's unit tests and the twelve GTK fixtures pass headless (Xvfb). The Flatpak was built on the GNOME 51 runtime, installed into a throwaway installation, and started its launcher, libadwaita and WebKitGTK and connected to a running Discord. Discord Rich Presence was checked against the Flatpak Discord, which accepted and showed the presence; the icon fix was not checked in a real game. Not run: a full release workflow, Roblox through Darling in the new Flatpak, and the Nix Rosemary package on a NixOS machine.

Fully close and reopen Quadra after updating. Studio is not in the Flatpak. OpenGL remains the default for the game on Darling; VR requires OpenGL or Vulkan/Zink. Native packages include the matching Metal host and framework. Install `.pkg.tar.zst` on Arch derivatives, `.deb` on Ubuntu 24.04+/Debian 13+, the binary `.rpm` on current Fedora, or the Flatpak with `flatpak install --user quadrahq-0.43.0-x86_64.flatpak` (it uses Flathub's GNOME 51 runtime). Darling/CiderDarling downloads remain separate. Source archives, build recipes and `SHA256SUMS` are attached.
