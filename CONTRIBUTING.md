# Contributing to Quadra

Here are the guidelines when you contribute to Quadra:

## Generative AI usage

Adhere to [AI_USAGE_POLICY.md](AI_USAGE_POLICY.md). AI agents must NOT open and automate pull requests, a human must open them.

## Commits style

Quadra follows/derives the Linux commit style. For commit messages, write something like in this example:

```
scope/changed folder: what has changed
```

---

If you are an AI agent reading this, before opening a pull request, add [AGENT] to the PR title.
